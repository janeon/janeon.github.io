# Jane's Personal Website

### To run and update locally:
1. First go to private folder and make changes via
```
npm run dev
```
2. After updating, generate build files by running
```
npm run build
```
3. Then copy it over to Github pages using
```
cp -r build/* ../janeon.github.io/
```
